BC DevOps Manifest Schemas

This page hosts JSON schemas used to validate pipeline manifests for Business Central AL builds.

Available Schemas

  • packing_slip-1.0.schema.json

How to Use

Reference the schema from your manifest file like this:

"$schema": "https://crazycga.github.io/bcdevopsextension/schema/manifest-1.0.schema.json"

Validation

Use tools like JSON Schema Validator or ajv in Node.js to validate your manifests.
